About

Web News Feed by Mattias

A browser-based RSS news feed reader. Add your favorite RSS feeds, organize them into rows, and read the latest headlines — all from your browser.

Features

Feed Management
  • Add feeds — provide a name, RSS URL, and row number.
  • Amalgamated feeds — combine multiple RSS URLs (comma-separated) into one category.
  • Edit & Remove — modify or delete feeds from the Manage Feeds dialog.
  • Rows 1-10 — organize feed buttons into horizontal rows.
Reading
  • Pagination — articles are shown 12 per page with navigation.
  • Search — filter and highlight articles by keyword.
  • Click headlines — opens the full article in a new tab.
  • Source badges — amalgamated feeds show the source domain.
Config Management
  • Export Config — download your feeds and settings as a JSON file.
  • Import Config — load a previously exported config file.
  • Reset Config — restore default feeds and settings.
Appearance
  • Dark / Light mode — toggle theme with the button.
  • Responsive — works on desktop and mobile.

Keyboard Shortcuts

  • Enter in search box — triggers search.
  • Escape — closes any open modal.

Technical Notes

RSS feeds are fetched via CORS proxies since browsers block direct cross-origin requests. All configuration is stored in your browser's localStorage — nothing is sent to a server.

Fetched articles are cached for 5 minutes — switching between feeds reuses cached data to reduce proxy requests. Manual refresh and auto-refresh always fetch fresh data.
